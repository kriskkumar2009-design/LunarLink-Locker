One Locker. Many Uses.

LunarLink Locker uses connected panels that can be taken apart and reused to create different structures.

📦 Pack

The locker can hold and organize supplies.

🔧 Unpack

The panels can be taken apart using removable connections.

🌙 Reuse

The panels can be rearranged into useful structures.
